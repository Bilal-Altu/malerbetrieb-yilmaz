# Fotos hier ablegen

Die Seite zeigt automatisch einen sauberen Platzhalter, solange eine Datei fehlt.
Sobald du eine Datei mit dem **exakt passenden Namen** hier ablegst, erscheint sie
von selbst – es muss kein HTML geändert werden.

| Dateiname               | Was drauf soll                                       | Format          |
|-------------------------|------------------------------------------------------|-----------------|
| `hero.jpg`              | Bestes Bild: Team auf der Baustelle / fertige Fassade | Hochformat 4:5  |
| `referenz-1-vorher.jpg` | Fassade **vor** der Sanierung                         | Querformat 16:10 |
| `referenz-1-nachher.jpg`| Dieselbe Fassade **nach** der Sanierung, gleicher Standpunkt! | Querformat 16:10 |
| `galerie-1.jpg`         | Innenanstrich, fertiger Wohnraum                      | Querformat 4:3  |
| `galerie-2.jpg`         | Trockenbau, abgehängte Decke                          | Querformat 4:3  |
| `galerie-3.jpg`         | Fassade mit Gerüst während der Arbeiten               | Querformat 4:3  |
| `galerie-4.jpg`         | Tapezierarbeiten, Detailaufnahme                      | Querformat 4:3  |
| `galerie-5.jpg`         | Renoviertes Treppenhaus                               | Querformat 4:3  |
| `galerie-6.jpg`         | Team oder Firmenfahrzeug mit Logo                     | Querformat 4:3  |
| `team.jpg`              | Hüseyin Yilmaz bzw. das Team                          | Hochformat 4:5  |
| `og-bild.jpg`           | Vorschaubild für WhatsApp/Facebook, 1200 × 630 px     | 1,91:1          |

## Beim Fotografieren

- **Vorher/Nachher vom exakt gleichen Standpunkt** – das ist der stärkste Effekt der Seite.
  Standort merken (Foto vom Handy-Standort machen) oder gleich markieren.
- Querformat für die Galerie, Hochformat nur für `hero.jpg` und `team.jpg`.
- Bewölkter Himmel oder früher Morgen/später Nachmittag – knallige Mittagssonne
  frisst die Farben und macht harte Schatten.
- Aufgeräumt: Kabel, Eimer, Kaffeebecher aus dem Bild.
- Menschen bei der Arbeit wirken deutlich besser als leere Räume – vorher kurz
  fragen, ob das Foto veröffentlicht werden darf (DSGVO / Recht am eigenen Bild).
- Vor dem Hochladen verkleinern: max. **1600 px** lange Kante, JPG, Qualität ~80.
  Sonst wird die Seite langsam, und Ladezeit ist ein Google-Rankingfaktor.
